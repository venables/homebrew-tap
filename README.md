# Homebrew Tap

Custom Homebrew formulas by [@venables](https://github.com/venables).

## Installation

```sh
brew tap venables/tap
```

## Formulas

| Formula                                              | Description                                                |
| ---------------------------------------------------- | ---------------------------------------------------------- |
| [wt](https://github.com/venables/wt)                 | A simple git worktree manager                              |
| [ccfix](https://github.com/venables/claude-copy-fix) | Un-wrap and clean up text copied out of the Claude Code UI |

### Install a formula

```sh
brew install venables/tap/wt
```

## Moved formulas

These moved to the [venabots](https://github.com/venabots/homebrew-tap) tap:

| Old name              | New formula                                                       |
| --------------------- | ----------------------------------------------------------------- |
| `anyagent`, `oneshot` | [venabots/tap/dash-p](https://github.com/venabots/dash-p)         |
| `review-prs`          | [venabots/tap/review-prs](https://github.com/venabots/review-prs) |

```sh
brew tap venabots/tap
brew install venabots/tap/dash-p
```
